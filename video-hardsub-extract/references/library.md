# 本地批量字幕资料库

## 使用

1. 双击安装后返回的“打开字幕工具.cmd”。
2. “导入多个视频”可多选；“导入文件夹”只导入该文件夹直接包含的视频。工具将视频复制进自己的资料库，不依赖原路径一直存在。
3. 选中视频点“字幕范围”，拖选画面字幕所在区域。字幕位置一致的多个视频可以一起设置；位置不同则分别设置。新视频默认全画面，可能包含其他画面文字。
4. 点“提取所选”或“提取全部待处理”，按队列依次处理。结果自动保存；失败一项不会停止后续视频。可在当前视频完成后暂停。
5. 选中历史记录，在右侧按时间逐条查看或复制全文。支持名称搜索、“全选当前列表”和 Ctrl/Shift 多选；先搜索再全选只选择当前可见记录。
6. “批量导出”输出各视频独立文件夹，包含文字稿.txt、字幕.srt；可选择同时导出视频。文字稿包含每条起止时间、底部或其他画面区域、位置和样式候选，SRT 保留原始时间轴；JSON 不出现在交付目录。
7. “删除所选”经确认后永久删除所选记录、工具保存的视频副本、结果与该项缓存。不会删除最初导入的原视频、已导出的文件和共享模型。

## 保存位置

新工具默认 D:/视频字幕工具；已有明确指定工作目录则复用。Windows 禁止系统盘，D 盘不可用时选择其他数据盘，不静默回退 C。工具不能改变浏览器原来的下载设置。

- local-tool：启动入口和程序。
- library/index.sqlite3：历史记录索引。
- library/items：每条视频的独立副本、结果和运行数据。
- tools：共享环境和模型。

关闭再打开可继续读已保存结果；中断的任务标记失败供重试。未提取的记录也保留视频。一个资料库同时只允许打开一个窗口。

“导入旧结果”可把含 run.json、文字稿.txt、字幕.srt 的既有结果收进资料库，需要其中记录的原视频仍可读取。旧结果保持原样。

## 精度与速度

批量版本沿用同一识别引擎和采样参数，没有通过降采样、裁短视频或缩减模型提速。框选正确范围可减少无关画面的计算；首次模型下载、视频长度、分辨率和字幕密度都会影响耗时。每个视频单独加载识别进程，模型文件共享，不能把短样本耗时当成任意长视频的承诺。

界面是本地自动时间线，未进行人工逐帧精校；不默认合成段落。类型、排版和颜色为可见特征或候选，具体字体未确认。

Windows NVIDIA 电脑可按[显卡加速说明](gpu.md)单独配置。通过真实识别自检后，本地工具可勾选“显卡加速”，继续使用同一 server 模型和 3 fps。显卡运行环境与普通环境分别保留，不向所有电脑承诺相同速度。

同位置、连续相同文字延长显示时段；不同文字、数字变化、空白后再次出现、不同位置分别记录，不按语义合并。原始时间轴与识别证据保留。全画面识别会包含角色名、标题和装饰文字；逐字动画、花体、竖排、手写及低清小字可能仍有残缺和误识别，需要看原画面核对。十几个秒的视频如果全画面文字多，也可能比固定底部字幕的更长视频耗时更多。已有记录的裁剪范围不会自动变更，需要全部画面文字时选中记录，将“字幕范围”改成“全画面”后重新识别。
